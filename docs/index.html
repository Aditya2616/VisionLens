YOUR OWN VIDEO

Upload and webcam need the local server, so they are not part of this static page. To try them:

pip install -e .
visionlens fetch-models
visionlens serve

Then open http://127.0.0.1:8106. Everything stays on your machine.

Uploads are processed in a temporary folder and deleted afterwards. The webcam starts only when you tap the button.

HOW IT WORKS

  1. Detect. D-FINE (a real-time DETR-family detector, Apache-2.0) runs every few frames (on a CPU or a GPU) and returns boxes, classes and scores.
  2. Track. My own ByteTrack-style tracker predicts every box with a Kalman filter, matches by IoU with the Hungarian algorithm, and rescues low-score boxes in a second pass. That is why the solid boxes stay put while the dashed raw boxes flicker.
  3. Describe. The track history becomes typed events (enter, leave, move, linger, proximity). A deterministic template groups them into a short summary; an optional small local language model may rewrite it, and a guard rejects any rewrite whose objects, counts, times, directions or verbs the events do not support and asks for another attempt (up to three). An optional small vision-language model adds a separate, labelled line about the scene, cross-checked against the objects the detector found.
